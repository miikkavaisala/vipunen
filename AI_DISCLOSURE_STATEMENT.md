## Not covered by this statement

The LLM *inside* the pipeline (`src/llm.py`) is not a coding agent: it
is the system under development. It runs a small quantized model (up to
~10B parameters) on the user's own local OpenAI-compatible server —
configured via `LLM_BASE_URL` / `LLM_MODEL` or the `--llm-url` /
`--llm-model` CLI flags; no endpoint or model is hardcoded in this
repository — and its job is to filter, summarize, and digest arXiv
papers, not to write this codebase. Its outputs (verdicts, digests) are
explicitly treated as routing signals, not sources of fact. During
development the pipeline was also evaluated with a second local model
(a 12B quantized variant); results are recorded in the development
repository's test notes.
